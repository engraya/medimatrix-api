# Files

One multipart PDF/JPEG/PNG up to 5 MiB; detected bytes must agree with declared MIME. Random keys prevent path injection. Metadata failures compensate storage writes. Owner/staff receive private five-minute signed URLs; staff access is audited. Local storage is development-only. Documents download as attachments.

Errors include FILE_REQUIRED, UNSUPPORTED_FILE and upload limits. Configure a browser-reachable S3_PUBLIC_ENDPOINT. Byte detection is not antivirus; add quarantine/scanning if ingestion requirements expand.
